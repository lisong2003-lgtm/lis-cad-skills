# 装饰算量（zhuangshi-suanliang）v0.9.0
**[English](./README.en.md) | [中文](./README.md)**


用于从房间类型或建筑/结构/装修做法信息快速生成装饰概算和物资计划。输出可核对台账、计算式、规范参考和待确认项。

## 0.9.0 优化概览

- 对接 `cad-file-reader >= 0.25.0` 的长度、面积、体积测量候选；面积/长度可转成待核对装饰输入，体积候选不直接导入。
- CAD 导入行做法编号留空、`需核对=是`，识图证据与正式清单量分开。
- 做法映射、洞口扣减、侧壁、损耗、材料台账和六表输出仍由本技能负责。

- 技能入口：`SKILL.md`
- 计算脚本：`scripts/decor_qty.py`
- 快速输入：`templates/快速概算输入表.csv`
- 明细输入：`templates/装饰算量输入表.csv`
- 房间模板：`rules/标准房间模板.json`
- 材料做法：`rules/装饰做法.json`
- 清单规则：`rules/清单工程量规则.json`
- 参考单价：`rules/概算综合单价.json`
- 物资分类：`rules/物资分类规则.json`
- 规范参考：`rules/国家规范要求.json`
- 项目专属示例：`templates/项目专属规则示例.json`

## 快速开始

### 1. 快速概算

按房间输入长、宽、高、周长、洞口和防水参数；脚本按房间模板展开做法。

```bash
python3 \
  scripts/decor_qty.py \
  --input templates/快速概算输入表.csv \
  --out-dir ./概算结果 \
  --project-rules templates/项目专属规则示例.json \
  --project 示例项目
```

### 2. 明细算量

已经拆分部位和做法编号时，直接使用明细输入。

```bash
cp templates/装饰算量输入表.csv ./输入.csv
python3 \
  scripts/decor_qty.py \
  --input ./输入.csv \
  --out-dir ./明细结果 \
  --project-rules templates/项目专属规则示例.json \
  --project 示例项目 --level 二层
```

## 输出

- `装饰概算物资计划台账.xlsx`：固定包含 `概算`、`物资计划`、`明细`、`汇总`、`缺项`、`依据` 六个工作表。
- `概算明细.csv`、`概算汇总.csv`：清单/商务口径工程量和合价。
- `物资计划.csv`：采购口径净量、损耗、需求量、供货方式和分类。
- `明细.csv`、`材料汇总.csv`：基面量、材料订货量、计算式、依据和状态。
- `缺项核对.csv`、`依据.csv`、`装饰概算物资计划报告.md`：待确认项和复核依据。

## 两条口径

- **概算量**：按清单/商务口径取基面量，不含损耗、卷材搭接和防水附加层。
- **物资计划量**：按采购口径计算，含损耗、卷材搭接、防水附加层；块料按单片面积向上取整。
- 清单编码和综合单价为内置参考；正式口径以合同清单、地方规则、企业定额、设计文件和现行规范为准。

## 校验与优先级

1. 项目专属做法必须填写节点编号、节点详图，并匹配 `--project-rules` 中的节点规则；未匹配时不回退默认做法。
2. 快速输入先按房间模板展开；未知房间类型进入待确认项。
3. 输入检查必填列、必填值、数字单位、负数、间数和完全重复行。
4. 防水校验附加层、搭接宽度、卷材幅宽、涂膜厚度、上翻高度和屋面道数。
5. 概算量与物资计划量分表输出，避免把采购量误当商务量。
6. 内置规范值和参考单价只是提示，不是条文原文或市场价替代。

## CAD 测量候选交接

`cad_measure.sh` 是识图底座 cad-file-reader 的脚本（本技能复用底座输入，仅在 cad-file-reader 技能目录下存在）：

```bash
# 在识图底座 cad-file-reader 技能目录执行：
scripts/cad_measure.sh 描述几何/图纸详情.descriptive.json --out-dir 测量候选
scripts/cad_measure_to_input.py --measurements 测量候选/cad-measurement-candidates.json \
  --out CAD导入_待核对.csv --floor 二层
```

CAD 导入行的做法编号保持为空、需核对固定为“是”；面积/长度只作识图证据，扣减、做法映射、损耗、材料台账和正式清单量仍由本技能计算。
