# Electrical Geometry / 电气识图中间数据包

本包是 `cad-file-reader` 的电气专业识图层，用于把变配电、照明、动力、应急照明、火灾报警（含消防水/喷淋/气体灭火/防排烟/防火卷帘/消防联动/消防泵）、安防、弱电/智能化（综合布线、CCTV、门禁、广播、BAS、能耗计量、智能照明、IBMS）和防雷接地图纸读成“专项 skill 可复核的中间数据”。

它只做识图和证据提取，不做算量、不输出工程量。配电箱、回路、管线规格、桥架、灯具、消防设备和弱电/智能化设备定位仍由 `anzhuang-suanliang` 或下游专项 skill 按各自口径处理。

## 触发

- 需要识别电气专业图纸类型、系统、图层、回路、设备、桥架/母线、消防、弱点/弱电或智能化候选。
- 需要把电气图纸先转成带坐标、图层、图框和原文证据的中间数据。
- 需要为机电算量、物资计划或专业软件交叉核对提供可追溯输入。

## 快速审计

```bash
scripts/cad_scan.sh 电气图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer \
  --detail-json 电气详情.json --format json -o 电气扫描

scripts/cad_electrical_geometry.sh 电气详情.json --out-dir 电气识图
```

输入必须是 `cad_scan` 生成的详情 JSON；没有 `geometry_segments` 或 `geometry_layers` 时只保留文字、块和待复核项，不伪造桥架/管线。

输出：

- `*.electrical.json`：电气识图候选、系统、回路、桥架/母线/导管、设备、标注、防雷接地、消防/弱点/智能化字段和证据。
- `*.electrical.md`：可读复核报告（含消防候选、弱点/弱电候选、智能化候选分节）。
- `*.electrical.csv`：候选台账（含领域行）。

## 中间数据契约

每个候选至少包含：

- `type`：图纸类型、系统、回路、路由段、设备、标注或复核项。
- `system`：变配电、照明、动力、应急照明、火灾报警、消防水、喷淋、气体灭火、防排烟、消防联动、消防泵、安防、综合布线、门禁、广播、BAS、能耗计量、智能照明、IBMS、弱电、防雷接地等候选。
- `route_class`：导管、电缆、导线、桥架、母线、消防总线火警环路、信号总线等候选。
- `domain`/`domain_label`：`fire_protection`（消防）、`weak_current`（弱点/弱电）、`intelligent_building`（智能化）三领域分组（有效时）。
- `layer`、`geometry`、`file`、`sheet`、坐标和原文证据。
- `confidence`：0~1。
- `status`：`candidate` 或 `review`。
- `review_reason`：缺图层、缺几何、比例/单位不明、系统归属不明等原因。

## 识别范围

- 图纸类型：配电/照明/动力平面图、系统图、干线图、详图、材料表/图例、防雷接地图、消防水/喷淋平面、消防联动平面、防排烟平面、气体灭火平面、智能化平面、综合布线平面、CCTV 平面、广播/会议平面。
- 专业系统：变配电、照明、动力、应急照明、火灾报警、消防水、喷淋、气体灭火、防排烟、疏散、消防联动、消防泵、安防、综合布线、门禁、广播/会议、BAS、能耗计量、智能照明、IBMS、弱电、防雷接地。
- 路由候选：导管、电缆、导线、桥架、母线槽、消防火警环路（fire_loop）、弱电信号总线（signal_bus）。
- 回路候选：按配电箱/楼层分组，识别回路编号（WL/WPM/L/M/FAS/FA/FBF/FB/FBN/XFB/XS/XQ/CCTV/PDS/ACS/PA/AV/IBMS/BMS/箱体代号等）及其规格候选。
- 设备候选：配电箱/柜、灯具、开关插座、应急照明设备、探测器、报警设备、消火栓、喷淋头、气体灭火设备、排烟口/阀、防火卷帘/防火门、消防泵、消防控制主机、防雷接地设备、摄像机、信息插座、机柜/配线架、门禁设备、广播音箱、DDC/BAS 传感器、能耗计量表、智能照明面板、网络设备等。
- 标注候选：回路规格、设备编号、系统标签、楼层标签；新增弱电/智能化型号（UTP/STP/CAT5E/CAT6/GYXTW/GYTA/FIBER 等）规格候选。
- 复核项：缺图层、缺几何、系统归属不明、比例/单位不明、防雷接地点位未绑定几何、消防/弱电/智能化系统归属需人工核对。

## 边界

- 不输出工程量、材料量、损耗、预留、订货量、造价或结算量。
- 不把候选回路规格展开为芯数、线长或端接量；回路关系仅作候选与复核输入。
- 不做配电箱母排计算、断路器整定、负荷计算、照度计算或设备表汇总。
- 系统图和设备表只做候选表，不做跨文件去重。
- 缺几何、缺图层、缺比例/单位或无法归属的结果必须进入 `review`。
- 不替代专业算量软件、设计审查、施工图预算和结算。
- 公司项目路径和公司图纸内容不得进入本技能发布内容。
