# Curtain Wall / 幕墙专业识图中间数据包

本包把幕墙深化图读成可复核的识图候选：图纸类型、系统、立柱/横梁/面板/开启/埋件构件、分格/标高/板块编号标注和图层面模型。

只做识图证据，不计算幕墙面积、板块数量、材料量或造价；算量交给幕墙/钢结构专项 skill。

## 触发
- 需要识别玻璃/石材/金属/单元式幕墙平面、立面、节点、埋件和开启扇图纸类型与系统。
- 需要给幕墙翻样/物资计划提供带坐标、图层、图框和原文证据的识图输入。

## 快速审计
```bash
scripts/cad_scan.sh 幕墙图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer --detail-json 幕墙详情.json --format json -o 幕墙扫描
scripts/cad_curtain_wall_geometry.sh 幕墙详情.json --out-dir 幕墙识图
```

输入必须是 `cad_scan --with-mtext --with-insert --with-geom --with-geom-layer` 的详情 JSON。

输出：
- `*.curtain_wall.json` / `.md` / `.csv`：幕墙识图候选与证据。

## 识别范围
- 图纸类型：幕墙平面/分格、立面、节点/剖面、预埋件、开启扇、材料/板块表。
- 系统：玻璃幕墙、石材幕墙、金属幕墙、单元式、立柱横梁支撑。
- 构件候选：立柱/竖挺、横梁/横挺、玻璃面板、石材面板、铝板、开启扇、预埋件/转接件、密封胶条。
- 标注候选：面板编号（MB/LM/HB/PM/CM）、标高、分格编号、预埋件编号。
- 复核项：缺几何、缺图纸类型、缺比例/单位、图层未分类、埋件/分格未绑定。

## 边界
- 不输出幕墙面积、板块数量、材料量、造价或结算量。
- 分格/标高/编号只作证据候选；缺比例/单位或未绑定几何时进入 `review`。
- 不替代幕墙深化设计、翻样下料、清单计价和结算。
