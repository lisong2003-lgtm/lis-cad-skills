# 土建算量性能与索引

## 时间都花在哪（实测）

| 场景 | 实测 |
|---|---|
| 21.7MB 图第一次索引（52,488 条文字 + 221,827 条线段） | 18–34 s |
| 之后每一层查询（同一张图，含层高自动反查、说明摘录、后浇带拆分） | **0.5–1.1 s** |
| 换一张新图 | 再付一次索引 |

索引按图纸内容 SHA-256 命名，图纸没变就永久复用；删掉 `.cadidx/<名字-哈希>/` 即强制重建。
建完索引自动回收解图明细 JSON：21.7MB 图的缓存从 64MB 降到 31MB（`--keep-detail` 可保留）。
输出头带口径版本与指纹（如 `口径 0.4.0+（运行输出显示实际版本与指纹）`），改过 `rules/口径.json` 一眼能看出来。
