# 土建算量（tujian-suanliang）
**[English](./README.en.md) | [中文](./README.md)**


给不会用广联达的施工员/技术员：**丢一张结构施工图，几分钟内拿到报物资计划要的量**。

- 按楼层（给图名就出那层）：梁、板、柱、墙的混凝土净量、订货量（含损耗）、标号分档、钢筋吨数带
- 按浇筑区：给了带长就把板量拆成「先浇区 + 后浇带封闭带（高一级微膨胀）」两笔，带宽自动从说明里读
- 截面/墙厚三级来源：图面标注就近绑 → 表格里按表头列名读 → 都没有就 `--member-size "KZ1=500x900,Q2=250"` 给一次，本图之后所有层沿用
- 快：一张图只解一次并建索引；之后任何一层查询不再碰图纸
- 洞口扣减：图面带尺寸的洞口自动扣（≥0.3㎡），结构图没注尺寸的照建施给一次 `--openings-m2`
- 通用：不依赖任何特定设计院的图层命名；换图换院自动重新判定图名与构件归属
- 诚实：缺依据的构件进"缺项清单"写明缺什么，绝不用默认值凑一个数冒充结果
- 规范校核：出量后提示标号缺失、常规尺寸异常和非正量；未标注混凝土强度等级不默认 C30，输出保持可核对的提示层
- v0.9.0：对接到 `cad-file-reader >= 0.25.0`（含旋转标注、图例匹配、跨专业引用与置信度候选） 的长度/面积/体积测量候选，仅作复核证据；土建净量、扣减、损耗和分账口径不变。

## 0.7.0 优化概览

- 本版重点是识图底座对接：测量候选只用于回图复核，不进入混凝土、钢筋、扣减或分账公式。
- 一次解图后继续复用索引和缓存；测量候选缺失或生成失败不阻断算量。
- 输出继续区分净量、含损耗订货量、标号分档、后浇带先浇区和封闭带，所有量均为计划口径。
- v0.6.0：接管 `cad-file-reader` 原结构算量流水线，新增梁对象、支座净跨、多跨闭合、实例去重、编号冲突、板厚分区、洞口、墙身闭合、预制底板、楼梯梁、结构模型和混凝土分账

```bash
# 常规楼层出量
scripts/run_qty.sh floors 图纸.dwg                       # 看这张图有哪些层
scripts/run_qty.sh floor 图纸.dwg --floor-label "三层梁平法施工图" \
  --axis-grid "8x8400,6x7800" --with-geom -o 该层计划

# 报「先浇 + 后浇带封闭」两笔（带长在平面图上量一次；带宽自动读说明）
scripts/run_qty.sh floor 图纸.dwg --floor-label "五层板配筋图" --with-geom --strip-length-m 120 -o 该层计划

# 高级结构算量流水线（迁移自 cad-file-reader）
scripts/run_qty.sh advanced 结构图.dwg \
  --floor-label "二层梁平法施工图" \
  --support-floor-label "标高X~Y墙柱平法施工图" \
  --slab-floor-label "二层板结构施工图" \
  --out 首层算量
```

**前置**：需已安装 `cad-file-reader >= 0.25.0`（本技能只调它识图、文字/图层/图框、几何线段与规范/图集元数据辅助）。**依赖**：Python ≥3.10；xlsx 需 openpyxl（Codex 自带运行时有），缺则自动只出 CSV/MD。

**规范边界**：GB 50500/50854 是口径背景，GB 550 系列和 16G/22G101 是读图/构造参考；知识库只存元数据或授权入口。规范校核只提示，不改量，不替代清单算量。

**边界**：计划口径毛量（未扣柱/节点/小于起扣面积的洞口，±5~10%；板按轴网分摊时 ±10~20%），可用于报计划、要方单、方案比选；**不能**用于翻样下料、对量、劳务结算、竣工计量。逐根钢筋长度与精确净量不在本技能范围。
