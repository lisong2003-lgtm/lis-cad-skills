# Descriptive Geometry / 装饰中间数据包

本包是 `cad-file-reader` 的画法几何识图层，用于把建筑图和装修表读成“装饰算量可复核的中间数据”。  
它是原创规则蒸馏，只使用在线资料的主题范围确认，不复制其正文、图片或页面版式。

## 触发

- 房间、墙面、地面、顶棚、门窗洞口、做法编号需要证据化提取。
- 需要判断图纸比例、单位、视图类型或投影对应关系。
- 装饰算量前需要先生成中间数据，而不是直接出量。

## 执行原则

1. 先用 `cad_scan` 低内存读取文字、图层、块名和图框；小图可用 `read_cad`。
2. 每条结果必须保留原文、图层、坐标、文件和图框证据。
3. 只输出候选中间数据；不把候选直接当最终工程量。
4. 平面图判断水平边界，立面/剖面判断高度和洞口，做法表判断材料做法。
5. 无法闭合或跨图框冲突的结果进入待确认项，不编造。

## 快速审计

```bash
scripts/cad_descriptive_geometry.sh 图纸详情.json --out-dir 描述几何
```

输入是 `cad_scan.sh ... --detail-json 图纸详情.json` 产生的详情文件。  
输出：

- `*.descriptive.json`：视图、比例、单位、房间、闭合边界、门窗归属、做法、节点索引和证据。
- `*.descriptive.md`：可读复核报告。
- `*.descriptive.csv`：候选台账。

## 中间数据契约

每个候选至少包含：

- `type`：房间 / 墙体 / 地面 / 墙面 / 顶棚 / 门窗 / 做法。
- `evidence`：原文、图层、坐标、文件、图框。
- `confidence`：0~1。
- `status`：`candidate`、`confirmed_by_rule` 或 `review`。
- `review_reason`：缺几何、跨图冲突、比例不明、做法缺失等原因。

几何专用字段：

- `room_boundaries`：闭合多边形、外接框、绑定房间名和证据线段。
- `wall_segments`：墙线 clear/opening 分段、显式墙高候选、门窗编号和图层证据。
- `ceiling_zones`：主吊顶、检修口、灯具带、造型、梁/降板影响、标高候选和父子分区索引。
- `stair_ramp_steps`：楼梯/坡道/台阶初稿，含显式面积、分项材料、级数、坡度、几何外接框和证据。
- `exterior_wall_zones`：外墙、保温层、防火隔离带、女儿墙内侧和立面饰面候选，含材料、厚度、标高和图层几何证据。
- `openings.geometry`：墙图层、墙线段、图面距离、房间边界和房间候选。
- `node_detail_index`：做法编号、节点编号、文件、图框和坐标。

闭合搜索默认最多检查 24 个横轴和 24 个纵轴；超过上限时只检查排序后的前部候选，并把结果转入复核。

顶棚候选只保留几何、文字和标高证据；不输出吊顶面积、扣减面积或材料需求量。  
楼梯/坡道/台阶只输出待确认初稿；显式面积和分项材料必须保留原文证据，不自动换算正式量。  
外墙分格与保温分区只输出候选证据；不输出外墙面积、保温面积、材料量或最终工程量。  
禁止在包内直接输出面积、体积或材料需求量；装饰算量仍由 `zhuangshi-suanliang` 按其口径处理。

## 投影校验规则

- 平面图：用于房间边界、墙体位置、门窗水平位置和洞口宽度。
- 立面图：用于层高、窗台高、门高、洞口高度和外立面分段。
- 剖面图：用于标高、降板、吊顶关系、梁高和上下层边界。
- 详图：用于构造层、收边、防水上翻、节点做法和材料分层。
- 做法表：用于做法编号与房间/部位的绑定，不替代几何尺寸。
- 节点详图：用于做法编号到节点编号的索引；构造层结论必须回到节点图或授权原文。

## 边界

- 不做设计合规审查、结算审计和最终量确认。
- 不复制原书全文；只保存可执行规则和证据。
- 大图禁止盲目全量解析；先低内存扫描，再按需读取。
- 公司项目路径和公司图纸内容不得进入本技能发布内容。
