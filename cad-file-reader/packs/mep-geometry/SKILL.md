# MEP Geometry / 安装识图中间数据包

本包是 `cad-file-reader` 的安装专业识图层，用于把电气、给排水、消防水、暖通、火灾报警、应急照明、弱电和燃气图纸读成“安装专项 skill 可复核的中间数据”。

它只做识图和证据提取，不做算量、不输出工程量。导管、桥架、管线、设备、回路和材料量仍由 `anzhuang-suanliang` 或其他专项 skill 按各自口径处理。

## 触发

- 需要识别安装专业图纸类型、系统、图层、路由、设备、标注、立管或连通性候选。
- 需要把安装图纸先转成带坐标、图层、图框和原文证据的中间数据。
- 需要给安装算量、安装物资计划或专业软件交叉核对提供可追溯输入。

## 快速审计

```bash
scripts/cad_scan.sh 安装图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer \
  --detail-json 安装详情.json --format json -o 安装扫描

scripts/cad_mep_geometry.sh 安装详情.json --out-dir 安装识图
# 可选：调整立管编号与路由段的关联距离（图面单位）
scripts/cad_mep_geometry.sh 安装详情.json --link-tolerance 2000 --out-dir 安装识图
```

输入必须是 `cad_scan` 生成的详情 JSON；没有 `geometry_segments` 或 `geometry_layers` 时只保留文字、块和待复核项，不伪造路由。

输出：

- `*.mep.json`：安装识图候选、系统、路由段、设备、标注、立管、竖向路由、系统拓扑、连通性审计和证据。
- `*.mep.md`：可读复核报告。
- `*.mep.csv`：候选台账。

## 中间数据契约

每个候选至少包含：

- `type`：图纸类型、系统、路由段、设备、标注、立管或复核项。
- `system`：电气、给排水、消防水、暖通、火灾报警、应急照明、弱电、燃气等候选。
- `route_class`：电线、导管、电缆、桥架、母线、给水管、排水管、消防管、喷淋管、风管等候选。
- `layer`、`geometry`、`file`、`sheet`、坐标和原文证据。
- `confidence`：0~1。
- `status`：`candidate` 或 `review`。
- `review_reason`：缺图层、缺几何、比例/单位不明、系统归属不明等原因。

## 识别范围

- 图纸类型：平面图、系统图、干线图、详图、材料表/图例。
- 专业系统：电气、给排水、消防水、暖通、火灾报警、应急照明、弱电、燃气。
- 路由候选：电线、导管、电缆、桥架、母线、给水管、排水管、消防管、喷淋管、风管、燃气管和通用 MEP。
- 设备候选：配电箱、灯具、开关插座、风机、风口、风阀、水泵、阀门、喷头、探测器、报警设备、卫生器具、水表/电表等。
- 标注候选：回路规格、管径、风管尺寸、设备编号、系统标签和楼层标签。
- 立管候选：`JL/PL/TL/FL/WL/YL/HL/RL/HYL/SPL/JFL/WFL` 等编号及专业归属。
- 连通性审计：端点吸附、开放端点、汇聚/分支候选和孤立段候选。
- 系统拓扑候选：按文件、图框和专业系统分组，输出闭合环、分支、开放端点和孤立段候选。
- 竖向路由候选：立管编号/竖向文字与最近路由段的关联候选，保留关联距离、方向和证据；只有竖向几何时进入 `review`。

## 边界

- 不输出工程量、材料量、损耗、预留、订货量、造价或结算量。
- 不把候选路由段长度当作最终管长；长度只作为单段图面几何证据。
- 不做回路规格匹配、管径推断、芯数展开、设备数量合计或跨图去重。
- 系统拓扑和竖向路由只作候选与复核输入，不推导实际立管长度、层高或工程量。
- 缺几何、缺图层、缺比例/单位或无法归属的结果必须进入 `review`。
- 不替代专业算量软件、设计审查、翻样、下料、清单编制和结算。
- 公司项目路径和公司图纸内容不得进入本技能发布内容。
