# Municipal Geometry / 市政专业识图中间数据包

本包是 `cad-file-reader` 的市政专业识图层，用于把道路、排水、管网、桥梁、涵洞、隧道、挡墙和交通照明等施工图读成“市政专项 skill 可复核的中间数据”。

它只做识图和证据提取，不做工程量计算。道路面积、土方、管道长度、井数、桥梁构件数量、钢筋量、混凝土量、材料量和造价仍由市政专项 skill 按各自口径处理。

## 触发

- 需要识别市政图纸类型、专业系统、道路/桥隧/管网构件、材料、桩号、标高、坐标或几何证据。
- 需要把市政图纸先转成带坐标、图层、图框和原文证据的中间数据。
- 需要给市政算量、施工组织、物资计划或专业软件交叉核对提供可追溯输入。

## 快速审计

```bash
scripts/cad_scan.sh 市政图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer \
  --detail-json 市政详情.json --format json -o 市政扫描

scripts/cad_municipal_geometry.sh 市政详情.json --out-dir 市政识图
```

输入必须是 `cad_scan` 生成的详情 JSON；没有 `geometry_segments` 或 `geometry_layers` 时只保留文字、块和待复核项，不伪造构件几何。

输出：

- `*.municipal.json`：市政识图候选、图纸类型、专业系统、构件、管网、材料、桩号/标高/坐标、连通性审计和证据。
- `*.municipal.md`：可读复核报告。
- `*.municipal.csv`：候选台账。

## 中间数据契约

每个候选至少包含：

- `type`：图纸类型、专业系统、构件、管网、材料、桩号/标高/坐标、市政几何或复核项。
- `category`：构件/管网类别，例如道路中线、路缘石、检查井、雨水口、管道、桥墩、桥台、桩基、箱梁、涵洞、隧道衬砌。
- `system`：道路、路面、土方、排水、雨水、污水、给水、再生水、热力、燃气、电力、通信、照明、交通、桥梁、涵洞、隧道、挡墙、边坡、综合管廊等候选。
- `layer`、`geometry`、`file`、`sheet`、坐标和原文证据。
- `confidence`：0~1。
- `status`：`candidate` 或 `review`。
- `review_reason`：缺比例/单位、缺几何、图层未分类、系统/构件无法映射、材料或标高缺失等原因。

## 识别范围

- 图纸类型：道路平面、纵断面、横断面、路面结构、交叉口、排水管网、管道纵断面、检查井详图、桥梁布置/构造、涵洞、挡墙、隧道、交通设施、道路照明和综合管线。
- 专业系统：道路、路面、土方、排水、雨水、污水、给水、再生水、热力、燃气、电力、通信、照明、交通、桥梁、涵洞、隧道、挡墙、边坡、综合管廊。
- 道路构件：道路中线、边线、路缘石、人行道、路面结构层、路基、边沟、边坡、挡墙。
- 桥隧构件：桥墩、桥台、桩基、承台、盖梁、箱梁/T 梁、支座、伸缩缝、涵洞、洞门、衬砌。
- 管网构件：排水管、雨水管、污水管、给水管、热力管、燃气管、电力/通信管、检查井、雨水口、泵站、阀门、管廊。
- 材料与做法：混凝土、砂浆、砖、钢筋、沥青、水泥稳定碎石、级配碎石、管材、灰土、土工布、防水和防腐。
- 标注与定位：桩号 `K0+000`、标高、`X/Y` 坐标、管径 `DN/De/D/Φ`、坡度、尺寸和比例单位。
- 几何与连通性：市政图层线段、端点吸附、开放端点、汇聚节点和孤立段候选。

## 边界

- 不输出道路面积、土方、管道长度、井数、桥梁构件数量、钢筋量、混凝土量、材料量、造价或结算量。
- 不把图面线段长度当作最终道路、管道或构件长度；长度只作为单段几何证据。
- 不做结构承载、水力计算、交通组织、施工方案、设计合规或规范条文符合性判断。
- 缺几何、缺图层、缺比例/单位、系统/构件无法映射、材料或标高缺失时进入 `review`。
- 不替代设计审查、测量放线、水力计算、结构计算、翻样、下料、清单编制和结算。
- 公司项目路径和公司图纸内容不得进入本技能发布内容。
