# Precast / 预制装配深化识图中间数据包

本包把预制装配深化图读成可复核的识图候选：图纸类型、系统、预制构件/预埋件/连接节点、构件编号/桁架筋/标高标注和图层面模型。

只做识图证据，不计算预制构件数量、体积、材料量或造价；算量交给 `tujian-suanliang` 或预制专项 skill。

## 触发
- 需要识别叠合板、预制墙、预制楼梯、预制梁柱、预埋件、构件拆分图图纸类型与系统。
- 需要给预制构件生产/运输/物资计划提供带坐标、图层、图框和原文证据的识图输入。

## 快速审计
```bash
scripts/cad_scan.sh 预制图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer --detail-json 预制详情.json --format json -o 预制扫描
scripts/cad_precast_geometry.sh 预制详情.json --out-dir 预制识图
```

输入必须是 `cad_scan --with-mtext --with-insert --with-geom --with-geom-layer` 的详情 JSON。

输出：
- `*.precast.json` / `.md` / `.csv`：预制装配深化识图候选与证据。

## 识别范围
- 图纸类型：叠合板/预制板、预制墙、预制楼梯、预制梁柱、预埋件图、预制构件拆分/构件表。
- 系统：预制墙、叠合板、预制楼梯、预制框架、预埋连接。
- 构件候选：预制墙板、叠合板/SP板、预制楼梯梯段、预制梁/柱、预埋件/吊点/灌浆套筒、连接节点/键槽/甩筋。
- 标注候选：构件编号（PC/DB/WB/NB/LB/TB/PB）、标高、桁架筋/钢筋、预埋件编号。
- 复核项：缺几何、缺图纸类型、缺比例/单位、图层未分类、构件/预埋未绑定。

## 边界
- 不输出预制构件数量、体积、材料量、造价或结算量。
- 构件编号/桁架筋/标高只作证据候选；缺比例/单位或未绑定几何时进入 `review`。
- 不替代预制深化设计、生产下料、吊装方案、清单计价和结算。
