# HVAC / 给排水深化识图中间数据包

本包把给排水、暖通/防排烟、消防水深化图读成可复核的识图候选：图纸类型、系统、管道/风管/设备/支吊架构件、管径/标高/编号标注和图层面模型。

只做识图证据，不展开管道长度、不计算风管面积、材料量或造价；算量交给 `anzhuang-suanliang` 或安装专项 skill。

## 触发
- 需要识别给排水/暖通/防排烟/消防水图纸类型、系统、管道风管、设备、支吊架候选。
- 需要给安装算量/物资计划提供带坐标、图层、图框和原文证据的深化识图输入。

## 快速审计
```bash
scripts/cad_scan.sh 给排水图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer --detail-json 给排水详情.json --format json -o 给排水扫描
scripts/cad_hvac_plumbing_geometry.sh 给排水详情.json --out-dir 给排水深化识图
```

输入必须是 `cad_scan --with-mtext --with-insert --with-geom --with-geom-layer` 的详情 JSON。

输出：
- `*.hvac_plumbing.json`：给排水/暖通深化识图候选与证据。
- `*.hvac_plumbing.md`：可读复核报告。
- `*.hvac_plumbing.csv`：候选台账。

## 识别范围
- 图纸类型：给水平面、排水平面、暖通/空调/通风平面、消防水平面、泵房、立管系统图、支吊架平面、风管大样。
- 系统：给水、排水、消防水、暖通、防排烟、冷凝水、支吊架。
- 构件候选：给水管、排水管、消防设备（喷淋头/消火栓/报警阀）、风机盘管/新风机组/风机、风口、风管、支吊架/抗震支架。
- 标注候选：管径（DN/De/D）、标高、设备编号、立管编号（JL/PL/FL/RL/WL/NL）。
- 复核项：缺几何、缺图纸类型、缺比例/单位、图层未分类、管径/标高未绑定构件。

## 边界
- 不展开管道长度、不计算风管面积、材料量、造价或结算量。
- 管径/标高只作证据候选；缺比例/单位或未绑定几何时进入 `review`。
- 不替代深化设计、翻样下料、清单计价和结算。
