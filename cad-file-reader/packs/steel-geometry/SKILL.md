# Steel Geometry / 钢结构识图中间数据包

本包是 `cad-file-reader` 的钢结构识图层，用于把钢结构设计说明、布置图、构件图、节点详图、材料表和预拼装图读成“钢结构专项 skill 可复核的中间数据”。

它只做识图和证据提取，不做重量、面积、长度汇总、材料量或工程量计算。钢材重量、涂装面积、螺栓数量、焊缝长度和材料量仍由钢结构专项算量 skill 按各自口径处理。

## 触发

- 需要识别钢结构图纸类型、结构系统、构件、截面、连接、材料、涂装、节点、轴网/标高或几何证据。
- 需要把钢结构图纸先转成带坐标、图层、图框和原文证据的中间数据。
- 需要给钢结构算量、深化设计、物资计划或专业软件交叉核对提供可追溯输入。

## 快速审计

```bash
scripts/cad_scan.sh 钢结构图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer \
  --detail-json 钢结构详情.json --format json -o 钢结构扫描

scripts/cad_steel_geometry.sh 钢结构详情.json --out-dir 钢结构识图
```

输入必须是 `cad_scan` 生成的详情 JSON；没有 `geometry_segments` 或 `geometry_layers` 时只保留文字、块和待复核项，不伪造构件几何。

输出：

- `*.steel.json`：钢结构识图候选、系统、构件、截面、连接、材料、涂装、节点、轴网/标高、连通性审计和证据。
- `*.steel.md`：可读复核报告。
- `*.steel.csv`：候选台账。

## 中间数据契约

每个候选至少包含：

- `type`：图纸类型、系统、构件、截面、连接、材料、涂装、节点、轴网/标高、钢构件几何或复核项。
- `category`：构件/连接类别，例如钢柱、钢梁、桁架、支撑、檩条、节点板、加劲肋、高强螺栓。
- `system`：钢结构、屋面、墙面、平台、钢楼梯、桁架、网架、支撑、预埋件、连接等候选。
- `layer`、`geometry`、`file`、`sheet`、坐标和原文证据。
- `confidence`：0~1。
- `status`：`candidate` 或 `review`。
- `review_reason`：缺比例/单位、缺几何、图层未分类、截面/材料缺失、构件编号无法映射等原因。

## 识别范围

- 图纸类型：钢结构布置图、构件图、节点详图、材料表、设计总说明、轴线/柱网图、预拼装图。
- 结构系统：钢框架、屋面结构、墙面结构、钢平台、钢楼梯、桁架、网架、支撑、预埋件、连接节点。
- 构件候选：钢柱、钢梁、桁架、支撑、檩条、拉条/系杆/隅撑、墙梁、平台、钢楼梯、栏杆、预埋件、节点板、加劲肋。
- 构件编号：`GZ/GL/GJ/XG/ZC/LT/TL/ML/GS/GC/GG/FHB/JDB` 等编号前缀及类别映射。
- 截面候选：H 型钢、槽钢、角钢、圆管、方管/矩管、C/Z 型檩条、钢板。
- 连接候选：焊接、高强螺栓、普通螺栓/锚栓、栓钉、节点板/连接板、加劲肋、支座/铰接/刚接。
- 材料候选：`Q235/Q345/Q355/Q390/Q420/Q460/S235/S355/A36/16Mn`。
- 涂装候选：热浸镀锌、防火涂料、底漆、面漆。
- 节点与轴网：节点编号、轴线、标高。
- 几何与连通性：钢构件图层线段、端点吸附、开放端点、汇聚节点和孤立段候选。

## 边界

- 不输出钢材重量、构件长度汇总、展开面积、涂装面积、螺栓数量、焊缝长度、材料量、造价或结算量。
- 不把图面线段长度当作最终构件长度；长度只作为单段几何证据。
- 不做连接承载力、节点设计、构件稳定性、防火等级或规范符合性判断。
- 缺几何、缺图层、缺比例/单位、构件编号无法映射、截面或材料缺失时进入 `review`。
- 不替代深化设计、结构计算、翻样、下料、清单编制和结算。
- 公司项目路径和公司图纸内容不得进入本技能发布内容。
