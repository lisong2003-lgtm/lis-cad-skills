# Site Geometry / 总图与场地识图中间数据包

本包把总图、竖向、管线综合、道路纵横断面、挡土墙/边坡、停车和景观图纸读成“专项可以复核”的场地识图候选。

只做识图和证据提取，不输出土方量、道路面积、管线长度汇总、材料量或造价；量交给市政/土建专项 skill。

## 触发
- 需要识别总平面、竖向、管线综合、道路、挡墙/边坡、停车、景观图纸类型和系统。
- 需要给场地土方、道路、管网算量提供带坐标、标高、桩号和原文证据的中间数据。

## 快速审计
```bash
scripts/cad_scan.sh 总图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer --detail-json 总图详情.json --format json -o 总图扫描
scripts/cad_site_geometry.sh 总图详情.json --out-dir 场地识图
```

输入必须是 `cad_scan --with-mtext --with-insert --with-geom --with-geom-layer` 的详情 JSON。

输出：
- `*.site.json`：场地识图候选与证据。
- `*.site.md`：可读复核报告。
- `*.site.csv`：候选台账。

## 识别范围
- 图纸类型：总平面、竖向设计、管线综合、道路平面/纵断/横断、挡土墙/边坡、停车、景观。
- 系统：场地、竖向、管线、道路、挡土墙/边坡、景观。
- 构件候选：场地红线/边界、道路、人行道、路缘石、停车位、挡土墙、护坡、排水沟、雨水口、检查井、管线（给水/排水/雨水/污水/燃气/电力/通信）、标高/高程点、土方（挖/填）、绿化铺装。
- 标注候选：桩号、坐标（X/Y/N/E）、标高、盘区编号、图层归属。
- 复核项：缺几何、缺图纸类型、缺比例/单位、标高/桩号未绑定几何。

## 边界
- 不计算土方量、挖填方量、道路面积、管线长度、材料量或造价。
- 标高等数值只作证据候选，缺比例/单位或未绑定几何时进入 `review`。
- 不替代设计审查、施工放线、清单计价和结算。
