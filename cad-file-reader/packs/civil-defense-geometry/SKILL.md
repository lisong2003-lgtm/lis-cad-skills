# Civil Defense / 人防工程识图中间数据包

本包把人防平面、防护密闭门、人防通风、人防墙节点、人防电气/给排水图纸读成可复核的识图候选：图纸类型、系统、防护设备构件、门号/抗力等级/标高标注和图层面模型。

只做识图证据，不计算人防结构量、材料量或造价；算量交给结构/土建专项 skill。

## 触发
- 需要识别防护单元、防护密闭门、密闭门、防爆波门、滤毒通风、洗消、人防电气等图纸类型与系统。
- 需要给人防战时布局/物资核查提供带坐标、图层、图框和原文证据的识图输入。

## 快速审计
```bash
scripts/cad_scan.sh 人防图.dwg --with-mtext --with-insert \
  --with-geom --with-geom-layer --detail-json 人防详情.json --format json -o 人防扫描
scripts/cad_civil_defense_geometry.sh 人防详情.json --out-dir 人防识图
```

输入必须是 `cad_scan --with-mtext --with-insert --with-geom --with-geom-layer` 的详情 JSON。

输出：
- `*.civil_defense.json` / `.md` / `.csv`：人防工程识图候选与证据。

## 识别范围
- 图纸类型：人防平面/分区、防护密闭门图、人防通风/滤毒图、人防墙节点、人防电气、人防给排水。
- 系统：防护单元/人防墙、防护门、人防通风、洗消排水、人防电气。
- 构件候选：防护密闭门、密闭门、防爆波门、临空墙/防护外墙、滤毒通风设备、洗消间/淋浴、防爆波电缆井/战时照明、后浇封堵/钢结构封堵。
- 标注候选：门编号（FM/HHFM/FHM/M）、标高、抗力等级、通风/电气设备编号。
- 复核项：缺几何、缺图纸类型、缺比例/单位、图层未分类、门号/抗力等级未绑定。

## 边界
- 不输出人防结构量、材料量、造价或结算量。
- 门号/抗力等级/标高只作证据候选；缺比例/单位或未绑定几何时进入 `review`。
- 不替代人防设计审查、施工验收、清单计价和结算。
