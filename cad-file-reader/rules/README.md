# CAD 规则与资料库说明

这个目录保存识图规则和规范/图集元数据，不建议堆放整本 PDF 或公司项目文件。

## 文件

- `standards.json`：图纸常见规范/图集的编号、名称、专业、状态、知识库相对路径和在线入口。
  只保存元数据与授权入口，不保存规范全文；`kb_path` 相对规范图集知识库根。
- 本技能只保留识图相关规则；梁板柱墙算量规则、口径和构造计算已迁到 `tujian-suanliang`。

## 规范辅助工作流

1. `cad_scan.sh --with-mtext --detail-json detail.json` 提取图纸说明。
2. `cad_normative.sh --scan scan.json --detail detail.json --rules rules` 输出：
   已索引/未索引编号、现行/旧版/待确认状态、资料入口、缺输入和参数冲突。
3. 报告不判定合规；条文适用性以图纸指定版本和正式授权全文为准。
4. 需要新增识图规则时，转换成带编号、条件、证据和不确定性的 JSON，不直接复制全文。
